## Proof the slope of the gradient is perpendicular to the slope of the level curves

The final step taken in finding the tangent vector as part of tool - analyse level curves performs the following simple step:

Say we have computed the gradient vector as:

$$
<a,\; b>
$$

Then, the tangent vector simply becomes:

$$
<-b,\;a>
$$

The negative reciprocal of a,b> But why is this possible? Here is a proof

Take a  multivariable function:

$$
w = f(x,\;y)
$$

where

$$
x=x(t),\; y=y(t)
$$

Then the gradient function can be computed as following using the chain rule:

$$
\nabla_w = \frac{\partial{w}}{\partial{x}}\frac{dx}{dt} + \frac{\partial{w}}{\partial{y}}\frac{dy}{dt} 
$$
